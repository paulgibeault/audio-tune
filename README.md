# Audio Tune

A soundboard, sound-design lab and step sequencer for
[Paul's Arcade](https://paulgibeault.github.io/), built on the framework's own
audio system (`arcade-sdk.js` + `arcade-audio.js`). It loads every fleet
game's shipped sound pack live, so each pad is the exact sound the game plays.

**Status: planning.** Nothing is implemented yet. Start with
[docs/soundboard-plan-2026-09.md](docs/soundboard-plan-2026-09.md).
